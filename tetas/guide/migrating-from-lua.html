Migrating from Lua ​

You know FiveM Lua — RegisterNetEvent, Citizen.CreateThread, exports, PascalCase natives. This page maps every one of those habits onto the .NET 10 runtime, side by side.

The big picture ​

AddEventHandler (local)[OnEvent("name")]

Events ​

lua
-- receive (networked)
RegisterNetEvent('shop:buy')
AddEventHandler('shop:buy', function(itemId, qty)
    local src = source          -- server side
    -- ...
end)

-- send
TriggerServerEvent('shop:buy', 42, 3)          -- client → server
TriggerClientEvent('shop:bought', src, 42)     -- server → client
TriggerClientEvent('announce', -1, 'hi all')   -- server → everyone
TriggerEvent('internal:refresh')               -- same side
csharp
// receive (networked) — source is injected, args are typed
[OnNetEvent("shop:buy")]
private void OnBuy([FromSource] ISharedPlayer buyer, int itemId, int qty)
{
    // ...
}

// send
API.EmitServer("shop:buy", 42, 3);             // client → server
API.EmitClient(serverId, "shop:bought", 42);   // server → client
API.EmitClient(-1, "announce", "hi all");      // server → everyone
API.EmitLocal("internal:refresh");             // same side

Watch out for:

  • RegisterNetEvent split into two attributes. [OnEvent] = local only, [OnNetEvent] = networked. A networked event hitting a plain [OnEvent] handler is silently dropped — the #1 migration bug. See Events.
  • source is not a global. It's a [FromSource] parameter — ask for it as ISharedPlayer, int, or string and the runtime injects the right shape.
  • Args are typed and validated. Where Lua would happily hand you nil, the C# runtime logs a warning and skips the handler if a required arg can't bind. Make trailing params nullable or defaulted for lenient input.

Threads & waiting ​

lua
Citizen.CreateThread(function()
    while true do
        DrawHud()
        Citizen.Wait(0)          -- every frame
    end
end)

Citizen.SetTimeout(2000, function()
    print('2s later')
end)
csharp
public void Initialize()
{
    _ = HudLoop();               // fire-and-forget = CreateThread
    API.SetTimeout(() => API.Log.Info("2s later"), 2000);  // note: action first!
}

private async Task HudLoop()
{
    while (true)
    {
        DrawHud();
        await API.Delay(0);      // == Citizen.Wait(0)
    }
}

Lua's "threads" are coroutines on the main thread — and so are C# async loops here, thanks to the runtime's SynchronizationContext. The mental model carries over 1:1. What's new is that .NET also gives you real OS threads (Task.Run) for heavy work — just never touch natives or emit events from them; hop back with await API.JumpToMainThread() first. Full rules in Threading.

Commands ​

lua
RegisterCommand('giveweapon', function(source, args, rawCommand)
    local targetId = tonumber(args[1])
    local weapon   = args[2]
    -- ...
end, true)   -- restricted
csharp
[OnCommand("giveweapon") { Restricted = true }]
private void GiveWeapon(
    [FromSource]     ISharedPlayer caller,
                     int targetId,          // args[1], already parsed
                     string weapon,         // args[2]
    [FromRawCommand] string raw)            // rawCommand, if you want it
{
    // ...
}

No tonumber, no manual args indexing — parameters are parsed positionally into your declared types. See Commands.

Exports ​

lua
-- expose (resource "bank")
exports('getBalance', function(playerId)
    return accounts[playerId].balance
end)

-- call from another resource
local bal = exports.bank:getBalance(playerId)
csharp
// expose (resource "bank")
[ExportMethod("getBalance")]
private int GetBalance(int playerId) => _accounts[playerId].Balance;

// call from another resource
int bal = API.Exports["bank"].Call<int>("getBalance", playerId);
API.Exports["bank"].CallVoid("deposit", playerId, 500);

You can also export plain values (API.Exports.Local.Set("version", "1.4.0")) and pass delegates across — they travel as function references, just like Lua closures do.

Natives ​

Native names are the same names you already know, converted from SNAKE_CASE to PascalCase — and every native page in the reference lists the Lua name so you can search either way.

lua
local ped    = PlayerPedId()
local pos    = GetEntityCoords(ped)
local veh    = GetVehiclePedIsIn(ped, false)
SetEntityCoords(ped, 0.0, 0.0, 72.0)
local model  = GetHashKey('adder')
csharp
using CitizenFX.FiveM.Server;   // client natives live here too — see Gotchas

int ped      = Native.PlayerPedId();
Vector3 pos  = Native.GetEntityCoords(ped, true);
int veh      = Native.GetVehiclePedIsIn(ped, false);
Native.SetEntityCoords(ped, 0f, 0f, 72f, true, false, false, false);
uint model   = API.Hash("adder");   // GetHashKey / joaat

Differences that will bite you:

  • No hashes, no Function.Call — every native is a real typed method with the hash baked in.
  • Floats are float. Lua's 0.0 becomes 0f; passing an int where a float is expected is a compile error, not a silent quirk.
  • Out-params are C# out. Where Lua returns multiple values, C# uses the return value plus out parameters: Native.GetVehicleInteriorColour(veh, out int colour).
  • Vectors are System.Numerics.Vector3 — with real operators and math methods.
  • Prefer the entity wrappers (vehicle.Position, ped.Health) where they exist; drop to Native.* for the rest.

A complete before/after ​

lua
RegisterNetEvent('greet:pong')
AddEventHandler('greet:pong', function(msg)
    print('server said: ' .. msg)
end)

RegisterCommand('hello', function()
    TriggerServerEvent('greet:ping', 'hi!')
end)
csharp
using CitizenFX.FiveM.Client;
using CitizenFX.FiveM.Shared.Script;

public class Main : IScript
{
    [OnCommand("hello")]
    private void Hello() => API.EmitServer("greet:ping", "hi!");

    [OnNetEvent("greet:pong")]
    private void Pong(string msg) => API.Log.Info($"server said: {msg}");
}
lua
RegisterNetEvent('greet:ping')
AddEventHandler('greet:ping', function(msg)
    local src = source
    print(GetPlayerName(src) .. ' pinged: ' .. msg)
    TriggerClientEvent('greet:pong', src, 'pong!')
end)
csharp
using CitizenFX.FiveM.Server;
using CitizenFX.FiveM.Shared.Script;
using CitizenFX.FiveM.Shared.Serialization;
using CitizenFX.FiveM.Shared.Entities;

public class Main : IScript
{
    [OnNetEvent("greet:ping")]
    private void Ping([FromSource] ISharedPlayer player, string msg)
    {
        API.Log.Info($"{player.Name} pinged: {msg}");
        API.EmitClient(player.Handle, "greet:pong", "pong!");
    }
}

Build it, ensure it, /hello — and you've migrated your first resource.
