Exports ​

Cross-resource calls, modelled as function references delivered through internal events and wrapped in a tidy accessor.

Exposing an export ​

csharp
// resource "bank"
public class BankApi : IScript
{
    // declarative:
    [ExportMethod("getBalance")]
    private int GetBalance(int playerId) => _accounts[playerId].Balance;

    // imperative — a value or a delegate:
    public void Initialize()
    {
        API.Exports.Local.Set("version", "1.4.0");
        API.Exports.Local.Set("deposit", new Action<int, int>(Deposit));
    }
}

Calling an export ​

csharp
// any other resource — indexer or Get() returns a BaseExportAccessor:
int bal = API.Exports["bank"].Call<int>("getBalance", playerId);
API.Exports["bank"].CallVoid("deposit", playerId, 500);

// values, too:
string ver = API.Exports.Get("bank").Call<string>("version");

How resolution works ​

ExportManager.Get(resource) returns the LocalExportAccessor for your own resource, otherwise a cached RemoteExportAccessor. Every export is stored behind an internal event named __cfx_export_<resource>_<name>; a remote read triggers that event and captures the answer.

csharp
// exposing: register a responder event once, keyed by export name
public void Set(string name, object? value)
{
    bool existed = _exportedValues.ContainsKey(name);
    _exportedValues[name] = value;
    if (!existed)
        _core.SharedEventManager.RegisterEvent(
            $"__cfx_export_{_core.ResourceName}_{name}",
            (Delegate)(cb => cb.CallVoid(_exportedValues.GetValueOrDefault(name))));
}

// reading a remote export: fire the event, grab the value via a callback
public override T? Get<T>(string name)
{
    T res = default;
    core.SharedEventManager.TriggerLocalEvent(
        $"__cfx_export_{_resource}_{name}",
        (Action<T>)(value => res = value));
    return res;
}

Methods are exported as FunctionReferences. The BaseExportAccessor caches the resolved function per export name, so repeated calls don't re-fire the resolver event:

csharp
public T Call<T>(string name, params object?[] args)
    => (GetFunction(name) ?? throw new KeyNotFoundException(
           $"Export {name} not found in resource {resource}")).Call<T>(args);

public void CallVoid(string name, params object?[] args)
    => (GetFunction(name) ?? throw ...).CallVoid(args);

// GetFunction(name) resolves Get<FunctionReference>(name) once, then caches it.
public void ResetFunctionCache();   // drop the cache manually if you need to

Automatic cache invalidation

The ExportManager subscribes to onServerResourceStart and removes the cached accessor for a restarted resource, so exports re-resolve cleanly after that resource restarts — no stale function references.

Passing callbacks

Because exports ride on function references, you can pass a Delegate as an argument and the other resource can invoke it later. See Serialization → function references.
